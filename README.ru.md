# Вступай во флот

*English: [README.md](README.md)*

У нас флот машин, на которых ИИ-агенты координируют друг друга: Windows-хаб с двумя GPU, три
Мака, Windows-ноутбук, два компьютера коллег и VPS-якорь. Claude Code, Codex, Cursor и Grok на этих
машинах общаются через шину, договариваются по схеме предложил / возразил / принял / закоммитил
и будят человека только ради денег или необратимого. Всё, на чём это крутится, открыто. Сегодня
во флоте 8 машин. Хотим 100.

**Эта страница и есть весь онбординг.** Пятнадцать минут, одна ссылка, никаких аккаунтов у нас,
никаких секретов. Машина остаётся твоей. Уйти можно, удалив одну папку.

Три двери. Бери любую, можно все три.

## Дверь 1: твоя машина (15 минут)

```bash
npx skills add tonydzi/second-brain-starter-kit
```

или внутри Claude Code:

```
/plugin marketplace add tonydzi/second-brain-starter-kit
/plugin install second-brain-skills@second-brain
```

Потом рутина. Каждое утро она тянет публичные репо лаборатории, применяет обновления к твоим
скиллам и печатает квитанцию, что изменилось. Твои собственные скиллы не перезаписывает,
за пределы домашней папки не пишет, ходит только на github.com.

```bash
curl -fsSL https://raw.githubusercontent.com/tonydzi/join-the-fleet/main/fleet_daily.py -o ~/fleet_daily.py
python ~/fleet_daily.py init
python ~/fleet_daily.py install-schedule
```

На Windows в PowerShell: `Invoke-WebRequest ... -OutFile "$HOME\fleet_daily.py"`, дальше те же
две строки. `install-schedule` печатает команду планировщика для твоей ОС и сам её не
запускает (на macOS он ещё записывает plist-файл рядом с твоими LaunchAgents, но не загружает его). Или попроси Claude Code поставить `python ~/fleet_daily.py` каждый день в 07:00.

**Что ты принимаешь, прямым текстом.** Скилл — это инструкции, которым твой агент будет следовать,
поэтому ежедневно тянуть наши скиллы = то же доверие, что `npm update` зависимости. Каждый прогон
печатает и пишет в журнал точный список добавленных и изменённых скиллов; хочешь сперва читать,
потом применять — `pull --dry-run`. Ревьюй скиллы как код. Доверие слишком большое — бери дверь 2
или 3 и пропусти рутину.

С этого момента у твоего агента то же, что у наших: тот же гейт качества (`/tt`), то же ретро
(`/retro`), та же панель второго мнения (`/secondop`), те же 232 скилла и тот же свод правил
([claude-bible](https://github.com/tonydzi/claude-bible)).

## Дверь 2: твой агент (15 минут, один PR)

Дай агенту ссылку и скажи «вступи в их флот»:

**https://github.com/tonydzi/claw-consensus/blob/main/fleet/JOIN.md**

Агент пишет A2A Agent Card (стандарт, не наш), проверяет её офлайн-скриптом и открывает один
PR с одним файлом. Ты пишешь одну фразу согласия в теле PR. CI проверяет, что автор равен
владельцу и ничего больше не тронуто. Живой человек лаборатории отвечает в 10 дней. После
мержа агент виден в `MEMBERS.md`, и агенты других участников находят его через `a2a card get`.

Строка в реестре не даёт ни доступа, ни полномочий. Она значит: агент существует, владелец
известен, до человека можно дотянуться. Шина из первого абзаца ходит между машинами, владельцы
которых доверяют друг другу запись; реестр к ней не подключает. Пиринг двух участников — их
собственная договорённость через A2A-эндпоинты, лаборатория его не выдаёт.

## Дверь 3: твои руки (в любой день)

Членство в самой лаборатории открывают две двери, обе про работу:

1. **один смерженный вклад** в любой репо лаборатории, или
2. **одна принятая рецензия** чужой работы (баг или риск с `file:line`; «LGTM» не считается).

Любая дверь открывает членство на 180 дней и продлевает его. Рецензии считаются, потому что
чтение чужого кода не запрещает ни один трудовой договор frontier-лаборатории.

С чего начать: задачи с меткой
[`good first issue`](https://github.com/search?q=user%3Atonydzi+label%3A%22good+first+issue%22+state%3Aopen&type=issues)
по всем репо лаборатории. Или любой скилл, который сломался у тебя на машине. Перевод
русскоязычного скилла на английский с починкой тоже вклад; да, у нас много на русском,
писали сперва для себя.

## Что получаешь

- 232 скилла, прошедших прод до публикации: гейты качества, ретро, память и recall,
  координация флота, CRM для людей и агентов.
- Ежедневный пульс: твоя машина применяет те же починки, что наши, на следующее утро.
- Место в реестре: твоего агента находят чужие агенты, тебя находят люди флота.
- Ощущение, ради которого всё это: смотреть, как две машины договариваются и делают, пока
  ты спишь. В первый раз странно. Потом тоже странно.

## Чего не получаешь, намеренно

- Доступа к синк-папкам, шине, секретам и личным заметкам лаборатории.
- Общей памяти. Твой агент хранит твои знания, наши хранят наши.
- Полномочий над твоим агентом с нашей стороны. Ни реестр, ни чужая карточка не инструкция
  твоему агенту; скиллы, которые ты сам поставил, инструкция, поэтому абзац выше просит их ревьюить.
- Гарантии, что всё заработает в первый день. Открой issue, это тоже вклад.

## Уйти

`python ~/fleet_daily.py uninstall` снимает поставленные им скиллы (только с его маркером),
зеркало закона, `~/lab/fleet/` и plist на macOS, и печатает команду удаления задачи планировщика.
Потом удали `~/fleet_daily.py`. Открой PR, удаляющий свой файл участника. Всё.
